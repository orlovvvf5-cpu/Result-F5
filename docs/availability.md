# Доступность данных, версия 0.2.0

12.10.2026 прочитаны официальные страницы amoCRM по ссылкам ниже. Предыдущий сетевой запрет 403 устранён. Реальный аккаунт и авторизация виджета не проверены: credentials не предоставлены. Документация не устанавливает здесь гарантированный срок хранения/полноту журнала; отсутствие события не доказывает отсутствие исторического факта.

| Показатель | API и точное поведение версии 0.2.0 | Ограничение |
|---|---|---|
| Новые сделки | GET /api/v4/leads?with=source,source_id, все страницы; created_at в календарном периоде аккаунта | Только доступные неудалённые карточки. Навсегда удалённые/скрытые записи не входят |
| Успешные сделки | GET /api/v4/events; filter[entity]=lead, filter[type]=lead_status_changed, диапазон created_at. value_after[0].lead_status.id = 142, before.id != 142, уникальные entity_id в периоде | По доступным событиям, не обязательно первый успех за жизнь сделки. Полнота старой истории не доказана |
| Время до наблюдаемого успеха | created_at из карточки + самый ранний доступный успешный переход внутри периода | Явно отличается от первого успеха за всё время. Если дата создания отсутствует хотя бы для одной сделки, среднее недоступно |
| Конверсия за 28 суток | Не рассчитывается | Нужна подтверждённая полнота когорты и история результатов за 28 суток. Сегодняшний статус не подставляется |
| Сумма успешных сделок | Не рассчитывается исторически | sale_field_changed существует, но история бюджета на момент успеха пока не восстановлена/не проверена. Текущую price не считаем прошлой. Не оплаты |
| Просроченные задачи на конец прошлого периода | Не рассчитывается | task_added/deleted/completed имеют пустые value_before/value_after; одного списка текущих задач недостаточно |
| Активные без следующей задачи на конец прошлого периода | Не рассчитывается | Нет полной реконструкции статусов/привязок/сроков/завершения/удаления задач на дату |
| Просроченные задачи сейчас | GET /api/v4/tasks; filter[is_completed]=0, filter[entity_type]=leads, все страницы; complete_till > 0 и раньше начала выгрузки | Отдельный текущий блок; данные не атомарные и зависят от прав |
| Активные без доступной задачи сейчас | Текущий status_id не 142/143, нет доступной незавершённой задачи с entity_type=leads и entity_id сделки | Скрытые права доступа могут скрывать задачи; поэтому «без доступной задачи», не доказанное отсутствие любых задач |

Фильтры берутся из текущих pipeline_id, responsible_user_id, source_id / _embedded.source. Они явно подписаны «сейчас». Смена назначения в прошлом не реконструируется. Для исторического сегмента на событие потребовалась бы история ответственного, воронки и источника. Названия пользователей и воронок берутся из API; недоступные названия заменяются реальными ID, не придуманными людьми.

## Прочитанная официальная документация

- [События и примечания](https://www.amocrm.ru/developers/content/crm_platform/events-and-notes): GET /api/v4/events, limit ≤ 100, фильтры даты/сущности/типа, before/after для lead_status_changed, account_id, события бюджета и задач. Права на сущности ограничивают результат.
- [Сделки](https://www.amocrm.ru/developers/content/crm_platform/leads-api): GET /api/v4/leads, limit ≤ 250, created_at/closed_at/price/ответственный, with=source,source_id. with=only_deleted возвращает ограниченные модели из корзины; они не содержат всех данных, нужных для исторического расчёта.
- [Задачи](https://www.amocrm.ru/developers/content/crm_platform/tasks-api): GET /api/v4/tasks, фильтры is_completed/entity_type, complete_till, entity_id, account_id.
- [Воронки и этапы](https://www.amocrm.ru/developers/content/crm_platform/leads_pipelines): успешный системный статус 142, неуспешный 143.
- [Аккаунт](https://www.amocrm.ru/developers/content/crm_platform/account-info): GET /api/v4/account?with=datetime_settings, _embedded.datetime_settings.timezone.
- [Пользователи](https://www.amocrm.ru/developers/content/crm_platform/users-api): GET /api/v4/users и доступные имена/ID.
- [Рекомендации API](https://www.amocrm.ru/developers/content/api/recommendations): до 7 запросов/сек на интеграцию, до 50/сек на аккаунт, обработка 429 и возможная блокировка при злоупотреблении. Виджет работает медленнее этих лимитов; другие интеграции тоже используют лимит аккаунта.
- [Левое меню](https://www.amocrm.ru/developers/content/web_sdk/left_menu): штатные left_menu/widget_page только для публичных интеграций с техническим аккаунтом; приватная версия использует UI-ссылку.

## Что требуется для недоступной истории

Проверить фактическую полноту журнала, восстановление бюджета, связи и времени жизни задач, удалённые сделки, переоткрытия и границы полномочий в реальном аккаунте. При невозможности реконструкции нужен сбор событий и регулярные снимки с подтверждённым покрытием. Без постоянно работающего сервиса нельзя собирать их при закрытом браузере. В этой версии сборщик, архив истории и OAuth-обмен не реализованы. Никаких секретов в браузерный ZIP не помещается.
