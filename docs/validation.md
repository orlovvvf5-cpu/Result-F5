# Проверки версии 0.2.0

- `npm test`: 23 теста прошли. Реальные схемы API с тестовыми записями: календарные границы и DST, выборки создания/успеха, повторные переходы, текущие задачи отдельно от истории, невозможность подстановки сегодняшних бюджетов/статусов, отсутствие истории и полей, фильтры по ID.
- API-адаптер: все страницы и дедупликация, 204, отсутствие next на полной странице, блокировка чужого origin/account_id, ошибки модели, незавершённая пагинация, ограниченный повтор 429, остановка при 403, отмена, запрет посторонних методов, отказ при неизвестном часовом поясе.
- Chromium / Playwright (`scripts/check-browser.py`): отсутствие демо вне amoCRM, загрузка замоканных API, имя и ID аккаунта, часовой пояс, корректные значения проверочных выборок, реальные относительные ссылки на ID, фильтры, неравные периоды, мобильная ширина 390 px, ошибки 403 аккаунта и событий. Все запросы GET. Ошибок JavaScript не обнаружено.
- Официальные страницы API прочитаны; матрица обновлена. Это не подтверждение авторизации сессионного чтения в конкретном аккаунте.

**Не выполнено:** установка ZIP 0.2.0 и запросы в клиентском аккаунте, сравнение с его списками/журналом, подтверждение полного покрытия старой истории. Автоматические проверки используют тестовые ответы, а не реальные клиентские данные. OAuth не реализован. Исторические бюджеты, конверсия и состояния задач не объявляются доступными.

PNG prototype-desktop/mobile — архивные скриншоты прежней демоверсии 0.1, не вид текущего аккаунта и не доказательство реального подключения.
